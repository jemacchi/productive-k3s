# Release Direction

The long-term release goal is coherence across the ecosystem, not independent version guessing.

## Direction

- `productive-k3s-cli` should guide users toward compatible bundles.
- `productive-k3s-core` and `productive-k3s-infra` should remain explicit about supported contracts.
- Public documentation should help users choose a supported path instead of mixing arbitrary versions.
- Private or commercial profiles should remain separated from public release messaging.

## Public expectation

Users should be able to understand:

- which repository they need;
- which path is stable enough to evaluate;
- where implementation-specific release details actually live.
