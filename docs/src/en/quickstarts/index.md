# Quickstarts

These quickstarts help users choose a practical starting path after they already understand the Productive K3S model.

The goal is simple:

- start with the path that matches your immediate need;
- keep the rest of the ecosystem understandable;
- avoid treating every repository as if it solved the same problem.
