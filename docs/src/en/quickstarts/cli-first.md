# CLI-Oriented Path

For users who want a higher-level experience from the beginning:

1. Start with `productive-k3s-cli`.
2. Use the CLI documentation to understand which `core` and `infra` bundles are considered compatible.
3. Drop into `productive-k3s-core` or `productive-k3s-infra` only when you need implementation-level detail.

The CLI path is about UX consolidation, not hiding the underlying repository boundaries.
