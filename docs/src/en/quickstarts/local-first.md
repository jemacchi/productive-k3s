# Local-First Path

For users who want to evaluate Productive K3S locally before adopting more complex infrastructure:

1. Start with `productive-k3s-core` to understand the runtime contract and supported local installation modes.
2. Move to `productive-k3s-infra` if you want repeatable local or opinionated infrastructure scenarios.
3. Adopt `productive-k3s-cli` when you want a more unified entry point across compatible bundles.

This path favors clarity and incremental adoption over abstraction first.
