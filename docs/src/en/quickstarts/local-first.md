# Local-First Path

For users who want to start simple and stay close to the technical base before moving to more complete solution paths:

1. Start with `productive-k3s-core` to install a real Kubernetes base in the simplest practical way.
2. Move to `productive-k3s-profiles` and `productive-k3s-infra` if you want curated deployment solutions instead of direct base-only work.
3. Adopt `productive-k3s-cli` when you want the same journey through the recommended unified interface.

This path favors learning the foundations first while keeping the door open to the wider Productive K3S experience.
