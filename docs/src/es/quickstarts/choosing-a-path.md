# Elegir un Punto de Entrada

Elegí según lo que realmente necesitás:

- Si querés empezar simple con una base real de Kubernetes, empezá por `productive-k3s-core`.
- Si querés desplegar una solución completa sobre una plataforma, seguí por `productive-k3s-infra`.
- Si querés caminos curados de solución como on-prem por SSH o una ruta simple sobre AWS, usá `productive-k3s-profiles`.
- Si querés extensiones curadas del cluster como storage, registry o management, seguí con `productive-k3s-addons`.
- Si querés la interfaz unificada más simple y recomendada, empezá por `productive-k3s-cli`.

Usá este portal para entender primero el modelo. Usá los repositorios dueños para ejecutar el flujo real.
