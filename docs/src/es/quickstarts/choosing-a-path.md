# Elegir un Punto de Entrada

Elegí según lo que realmente necesitás:

- Si querés la base técnica y la lógica de instalación, empezá por `productive-k3s-core`.
- Si querés escenarios de infraestructura ensamblados alrededor del core, empezá por `productive-k3s-infra`.
- Si querés la experiencia más alta a nivel usuario, empezá por `productive-k3s-cli`.
- Si estás explorando extensiones opcionales, seguí con `productive-k3s-addons`.

Usá este portal para entender la división. Usá los repositorios dueños para ejecutar el flujo real.
