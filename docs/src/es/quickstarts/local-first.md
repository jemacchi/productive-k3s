# Camino Local Primero

Para usuarios que quieren evaluar Productive K3S localmente antes de adoptar infraestructura más compleja:

1. Empezá con `productive-k3s-core` para entender el contrato de runtime y los modos locales soportados.
2. Pasá a `productive-k3s-infra` si querés escenarios locales repetibles o flujos opinados de infraestructura.
3. Adoptá `productive-k3s-cli` cuando quieras un punto de entrada más unificado entre bundles compatibles.

Este recorrido prioriza claridad y adopción incremental antes que abstracción temprana.
