# Camino Orientado a CLI

Para usuarios que quieren una experiencia de más alto nivel desde el principio:

1. Empezá con `productive-k3s-cli`.
2. Usá su documentación para entender qué bundles de `core` e `infra` se consideran compatibles.
3. Bajá a `productive-k3s-core` o `productive-k3s-infra` solo cuando necesites detalle de implementación.

El camino CLI busca consolidar la UX, no esconder los límites entre repositorios.
