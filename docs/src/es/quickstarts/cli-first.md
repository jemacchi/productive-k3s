# Camino Orientado a CLI

Para usuarios que quieren la experiencia Productive K3S más simple y recomendada desde el principio:

1. Empezá con `productive-k3s-cli`.
2. Usá su documentación para entender qué capacidades de `core` e `infra` te está exponiendo para tu workflow.
3. Bajá a `productive-k3s-core`, `productive-k3s-infra`, `productive-k3s-profiles` o `productive-k3s-addons` solo cuando necesites detalle a nivel componente.

El camino CLI busca una mejor UX normal, no esconder los límites entre repositorios.
