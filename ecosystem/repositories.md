# Productive K3S repositories

## `productive-k3s`

Umbrella repository for documentation, roadmap, positioning, ecosystem overview, website content, and public entry points.

## `productive-k3s-core`

Core K3S installation engine and base runtime.

## `productive-k3s-infra`

Infrastructure automation, profiles, OpenTofu, Ansible, environment configuration, and scenario assembly.

## `productive-k3s-cli`

Unified command line interface over the Productive K3S ecosystem.

## `productive-k3s-profiles-pro`

Private and monetizable infrastructure profiles and enterprise use cases.

## `productive-k3s-addons`

Optional addons, integrations, examples, and experimental stacks.
